🎨 DESIGN DECISIONS

[✅] Unified Mode by Default
   RATIONALE: More training stability, better for MVP
   - All weed types merged into single class
   - ~4x more training samples per class
   - Simple, clear demonstrations

[✅] Separate Multiclass Support
   RATIONALE: Future extensibility
   - Optional mode for detailed analysis
   - Can preserve weed type differentiation
   - Easy switching via config

[✅] Modular Architecture
   RATIONALE: Extensibility and maintainability
   - Each module is independent
   - Loose coupling
   - Reusable components

[✅] Tile-Based Large Image Processing
   RATIONALE: Handle real-world orthomosaics
   - No image size limitations
   - Automatic tiling and merging
   - Preserves geographic information

[✅] Geographic Integration
   RATIONALE: Spatial analysis capabilities
   - Automatic coordinate extraction
   - Future GeoTIFF support
   - Visualization-ready

💡 TIPS FOR BEST RESULTS

Training:
  • Use GPU for best results (50x faster than CPU)
  • 30 epochs is good baseline, try 50-100 for production
  • Batch size 16+ recommended (8+ minimum)
  • Monitor training plots for overfitting

Inference:
  • Start with confidence threshold 0.25
  • Adjust down (0.15-0.20) for higher recall
  • Adjust up (0.30-0.45) for higher precision
  • Use tile-based for images >1024x1024

Heatmaps:
  • Image-space heatmaps best for large single images
  • Geo-aggregated best for multi-image sequences
  • Interactive map requires coordinate data
